# Навыки для Claude Code

Три навыка (skills) для Claude Code. Каждый лежит в папке `skills/<имя>/` и содержит `SKILL.md`.

## generate-and-verify
Подход «генерируй и проверяй»: сначала проверяющий, затем варианты, бюджет попыток, эскалация, цикл обучения.
Применение: задачи, где результат можно проверить (код, расчёты, сверки), поиск лучшего объекта, оптимизация,
проектирование ИИ-автоматизации. Включает порождение гипотез, эволюционный цикл и независимую перепроверку находок.

## dividend-stories
Дивидендные истории на Мосбирже: статус и даты выплаты, последний день покупки (T+1), доходность после НДФЛ,
история гэпа и роста перед отсечкой, журнал прогнозов с проверкой после события.
Скрипты: `div_history.py`, `div_forecast.py`, тесты `test_div.py` (Python 3.9+, пакет `requests`).
**Не инвестиционная рекомендация.** Цифры из пилота нужно перепроверять; они описывают прошлое, а не будущее.

## fair-value-moex
Справедливая стоимость акции Мосбиржи несколькими независимыми методами, сравнение с ценой и отбор кандидатов
в недооценённые со сверкой данных, ловушками стоимости и честной базовой частотой.
Версия 4: будущие доходы по ступеням надёжности — отчитанные кварталы (LTM) и дивиденды с решением совета директоров
входят в оценку, прогнозы агрегатора считаются отдельно; стоимость через 12 месяцев и чувствительность к форвардной ставке ОФЗ.
**Не инвестиционная рекомендация.**

## Установка
Скопируйте нужную папку из `skills/` в `~/.claude/skills/` (Windows: `C:\Users\<вы>\.claude\skills\`).
Скрипты `dividend-stories` запускайте на своём компьютере: сервисы данных (MOEX ISS, smart-lab) из облачных окружений недоступны.
